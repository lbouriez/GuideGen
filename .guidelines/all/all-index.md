# All Guidelines

> Comprehensive overview of guidelines for this project, covering best practices for logging, testing, and code organization.

## Quick Reference

Critical rules for development:

- ✅ DO: Use `console.log` for logging purposes
- ✅ DO: Use path aliases for imports starting with `@/`
- ✅ DO: Use relative imports for local dependencies
- ❌ NEVER: Use other logging libraries or frameworks
- ❌ NEVER: Use `require()` for imports
