# Browsing Project Guidelines

> Browse and search project guidelines to find specific documentation, understand project conventions, or explore available guidelines.

## When to Use

Use this skill when:
- You need to find specific documentation for a task or feature.
- You want to understand project conventions and best practices.
- You need to explore available guidelines for a particular technology or tool.

## Prerequisites

- Familiarity with the project's directory structure
- Access to the project's guidelines repository

## Workflow

### Step 1: Access the Guidelines Repository

**Guideline**: [Project Directory Structure](../../.guidelines/all/project-structure.md)

**Actions**:
1. Open the project's repository in your file explorer or IDE.
2. Navigate to the `.guidelines` directory.

**Verification**:
- [ ] The `.guidelines` directory is accessible and contains multiple subdirectories.
- [ ] You can see a list of available guidelines in the `all` subdirectory.

### Step 2: Search for Relevant Guidelines

**Guideline**: [Searching Guidelines](../../.guidelines/all/searching-guidelines.md)

**Actions**:
1. Use your IDE's search function or a search tool to find guidelines related to your task or question.
2. Browse through the search results to find the most relevant guidelines.

**Verification**:
- [ ] You have found at least one relevant guideline for your task or question.
- [ ] You can open and read the guideline to understand its content.

### Step 3: Review Backend Guidelines (if applicable)

**Guideline**: [Backend Guidelines](../../.guidelines/backend/custom-error-classes.md)

**Actions**:
1. If your task is related to backend development, review the backend guidelines.
2. Read through the guidelines for custom error classes, dependency injection, error handling, layer separation, and service naming conventions.

**Verification**:
- [ ] You have reviewed the relevant backend guidelines.
- [ ] You understand how to apply the guidelines to your task or feature.

### Step 4: Review Testing Guidelines (if applicable)

**Guideline**: [Testing Guidelines](../../.guidelines/all/vitest-testing.md)

**Actions**:
1. If your task involves testing, review the testing guidelines.
2. Read through the guidelines for test organization, mocking strategies, and console logging.

**Verification**:
- [ ] You have reviewed the relevant testing guidelines.
- [ ] You understand how to apply the guidelines to your task or feature.

### Step 5: Apply Guidelines to Your Task

**Guideline**: [Applying Guidelines](../../.guidelines/all/applying-guidelines.md)

**Actions**:
1. Apply the guidelines you have reviewed to your task or feature.
2. Ensure that your code follows the project's conventions and best practices.

**Verification**:
- [ ] Your code follows the project's conventions and best practices.
- [ ] You have applied the relevant guidelines to your task or feature.

## Common Issues

### Issue: Unable to Find Relevant Guidelines
**Solution**: Try using different search terms or browsing through the guidelines repository to find relevant guidelines.

### Issue: Unclear or Outdated Guidelines
**Solution**: Reach out to the project maintainers or contributors to clarify or update the guidelines.
