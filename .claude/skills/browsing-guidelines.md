# Browsing Guidelines

> Browse and search project guidelines to find specific documentation, understand project conventions, or explore available guidelines.

## When to Use

Use this skill when:
- You need to find specific documentation for a task or technology.
- You want to understand project conventions and best practices.
- You need to explore available guidelines for a particular domain (e.g., backend, frontend).

## Prerequisites

- Familiarity with the project's guideline structure and location.
- Access to the project's documentation repository.

## Workflow

### Step 1: Identify the Guideline Category

**Guideline**: [Project Guideline Structure](../../.guidelines/all/project-structure.md)

**Actions**:
1. Determine the category of the guideline you need (e.g., backend, frontend, testing).
2. Navigate to the corresponding guideline directory.

**Verification**:
- [ ] You are in the correct guideline directory.
- [ ] You can see a list of relevant guidelines.

### Step 2: Search for a Specific Guideline

**Guideline**: [Searching Guidelines](../../.guidelines/all/searching-guidelines.md)

**Actions**:
1. Use the search function to find a specific guideline (e.g., "mocking strategies").
2. Browse the search results to find the relevant guideline.

**Verification**:
- [ ] You have found the relevant guideline.
- [ ] You can access the guideline's content.

### Step 3: Review the Guideline Content

**Guideline**: [Guideline for Mocking Strategies](../../.guidelines/all/mocking-strategies.md)

**Actions**:
1. Read the guideline's introduction and overview.
2. Review the guideline's sections and subsections.
3. Take note of any relevant code examples or snippets.

**Verification**:
- [ ] You understand the guideline's purpose and scope.
- [ ] You can apply the guideline's recommendations to your work.

### Step 4: Explore Related Guidelines

**Guideline**: [Guideline for TypeScript Imports](../../.guidelines/all/typescript-imports.md)

**Actions**:
1. Identify related guidelines that may be relevant to your task (e.g., "TypeScript imports").
2. Browse the related guidelines to gain a deeper understanding of the topic.

**Verification**:
- [ ] You have explored relevant related guidelines.
- [ ] You can see how the guidelines relate to each other.

## Common Issues

### Issue: Unable to Find a Specific Guideline
**Solution**: Check the project's guideline structure and search function. If the guideline is not found, consider reaching out to the project maintainers or contributors.

### Issue: Guideline is Outdated or Incomplete
**Solution**: Check the guideline's version history and look for any updates or revisions. If the guideline is still outdated or incomplete, consider contributing to the project by updating the guideline.
